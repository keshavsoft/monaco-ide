The Problem

The Disconnected Editors Dilemma

In a 50/50 dual Monaco setup, having the source JSON on the left and the query result on the right is only half the battle. If you query $.rawAst.loc.start and see:

{ "line": 1, "column": 0, "index": 0 }

You still don't know where that object lives within the 11,000 lines on the left. The user must manually scroll, guess, or use Ctrl+F to hunt down the block.

The Solution

The Synchronized Highlighting Engine

The Traceability module hooks the lifecycle of both Monaco editor instances:

  1. Automatic Query Tracking: Upon executing any search, actions.highlightPathInSource() extracts the target key, searches the Monaco model text, applies a glowing blue Monaco line decoration, and centers it via revealLineInCenter().
  2. Click-to-Locate: Clicking any line or property in the Right Result Editor inspects the clicked key and immediately scrolls the Left Source Editor to that exact location.
  3. Zero Performance Penalty: Uses Monaco's high-performance native deltaDecorations API with zero DOM re-rendering overhead.
