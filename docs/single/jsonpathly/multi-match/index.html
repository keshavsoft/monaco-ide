The Problem

The Array Overload Problem

When a user queries a wildcard AST collection, such as:

$.rawAst.program.body[*]

The Right Editor dumps 14, 50, or 200 items in a giant JSON array. The user has no way to correlate item #7 in the right output array with its corresponding line in the left source tree.

The Solution

How Contextual Stepping Works (stepper/actions.js)

Rather than cluttering the screen permanently, the stepper is strictly contextual:

  1. Automatic Visibility Detection: If a query returns 0 or 1 match, the stepper stays completely hidden, maintaining the clean simplicity of V2.
  2. Contextual Stepper Pill: When matches > 1, a subtle pill appears in the top header: [ ◄ ] 1 of 14 [ ► ].
  3. Synchronized Stepping: Pressing F3 (Forward) or Shift + F3 (Backward) cycles to the next match, immediately illuminating that node's source line on the Left Monaco Editor.
