The Problem

The Tyranny of Obscure Schema Names

ASTs generated by Babel, TypeScript, or ESLint scanners contain hundreds of distinct node types and deeply nested structures. A developer wanting to extract function arguments often doesn't know whether the key is called params, arguments, or parameters.

Without autocomplete, the developer is forced to constantly break their mental flow, scroll back and forth, and visually verify spellings.

The Solution

How Zero-Backend Introspection Works (schemaIntrospector.js)

Unlike heavy language servers that require Node.js, WebAssembly binaries, or JSON Schema files:

  1. Direct Tree Traversal: The introspector inspects the active in-memory JavaScript object already parsed in the Left Monaco Editor.
  2. Real-time Path Parsing: When the user types $.rawAst., it parses the query segments, descends into data.rawAst, and extracts Object.keys().
  3. Array-Awareness: If an array is encountered (e.g. body[0].), it introspects the first array item's properties automatically.
  4. Floating Palette UX: Renders a sleek floating palette that handles ▲ / ▼ cycling and Tab completion, vanishing immediately when the query executes.
