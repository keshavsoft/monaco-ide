Zero-Typing AST Exploration

Right-Click Node Inspection & Alt+Click

Why should developers memorize and type complex paths through 11,000 lines of AST? Invert the workflow: point at any line in Monaco, right-click, and let the editor construct the query for you.

The Problem

The Friction of Manual Query Typing

When inspecting large AST documents like Babel scans (raw-ast.json), nodes are deeply nested inside multiple layers of program bodies, declarations, and location tokens:

$.rawAst.program.body[0].declarations[0].init.callee.name

Typing this path by hand requires scrolling through thousands of lines to verify key names, remembering array indices, and avoiding single-character typos that cause silent query failures.

The Solution

How Path Reconstruction Works (pathResolver.js)

When the user right-clicks or presses Alt + Click on any line in the Left Monaco Editor:

  1. Cursor Capture: Monaco delivers the exact line number (pos.lineNumber).
  2. Hierarchical Scope Walk: pathResolver.js scans backwards from line 1, tracking object scopes ({ }), array scopes ([ ]), and property keys.
  3. RFC 9535 Assembly: Assembles the canonical JSONPath string in under 0.1ms.
  4. Instant Query & Render: Injects the path into the top search bar, highlights the source line, and immediately executes jsonpathly.query() on the Right Editor.
