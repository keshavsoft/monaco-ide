The Evolution Story

Why We Built the "Single" Edition

While the full Monaco IDE is a comprehensive web-based IDE with in-browser virtual servers and multi-project workspaces, everyday editing tasks demand a featherlight, focused canvas. The Single edition progressively strips away unnecessary weight to deliver peak velocity:

1 V1: Focused Core

Stripped out the virtual server while keeping the explorer sidebar, Quick Open (Ctrl+P), and split preview.

2 V2: No Explorer

Eliminated the workspace directory tree. 100% of viewport width dedicated to Monaco with direct file picker (Ctrl+O).

3 V3: Strict Single

Removed multi-tab management. Exactly one file in memory with native disk persistence via Ctrl+S.

4 V4: Streamlined Studio

Ultra-lean 42px header, active file indicator, and zero-latency BroadcastChannel live sync to preview (Ctrl+Enter).

Declarative Architecture

Powered by Declarative DOM Primitive Bindings

Like all KeshavSoft projects, every Single edition adheres strictly to declarative separation of concerns:

1. bindings.json
Declarative map binding events (click, keydown) to named actions without imperative event loops.
2. actions.js
Pure, decoupled domain functions executed when events fire (e.g. openFile, playHtml).
3. state.js / channel
Reactive state & zero-latency BroadcastChannel broker synchronizing data models across browser tabs in real time.
