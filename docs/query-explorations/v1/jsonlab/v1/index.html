JSONLab

Web-based Monaco JSON editor

Why this project is in the lab

Monaco-based editor with query mode; query results can be applied to the main editor. Useful for studying editing/query integration.

What we want to learn: How a query panel relates to the editable source document and how edits are committed.

Controlled experiment — same input

Use the exact same JSON document for every project. Import sample.json into the external tool; this page does not upload your document automatically.

  1. Open/import the shared sample into the main editor.
  2. Enter Query Mode and choose JSONPath as the query engine.
  3. Run $.rawAst.program.body[*].type and inspect live result behavior.
  4. Observe whether query results replace or transform the active document.
  5. Test undo/redo and confirm the original document can be recovered.

Record observations

For this V1 pass, record what the project actually does. Do not infer a feature from marketing text.

  • What worked exactly as expected?
  • What was missing or difficult to discover?
  • Did an action change the source JSON or only display a result?
  • Could the result identify the exact source node, including duplicate keys?
  • What behavior should we learn from, avoid, or improve in Monaco IDE?
