Controlled experiment — same input

Use the exact same JSON document for every project. Import sample.json into the external tool; this page does not upload your document automatically.

  1. Open the shared sample as a JSON document and verify editing/formatting.
  2. Place the cursor on rawAst → program → body → the FunctionDeclaration entry; use Copy Path at Cursor.
  3. Run $.rawAst.program.body[*].type and inspect how query results are presented.
  4. Check whether a result can navigate back to its exact source location.
  5. Check whether query results can safely modify the source document, or are read-only extracts.
