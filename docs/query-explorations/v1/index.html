Query Explorations

A controlled comparison lab for existing JSON editors and JSONPath tools. Every experiment uses the same JSONPathly AST sample so we can compare editing, path discovery, querying, match navigation and source traceability against the same data.

Purpose: learn from existing products before building more. These are external references, not dependencies or copied implementations. Each project has its own isolated v1 folder.

Shared test fixture

All six experiments use the same file copied from docs/single/jsonpathly/v1/sample.json. It contains an AST-like document with four entries in rawAst.program.body, giving us nested objects, arrays, repeated property names and source-location metadata to investigate.

Download shared JSON sampleRFC 9535 ↗

Common query set

  • $.rawAst.program.body[*].type — multiple matches.
  • $.rawAst.program.body[2] — inspect the third AST body node.
  • $.rawAst.program.body[?@.type == "FunctionDeclaration"] — filter by node type.
  • $.rawAst.program.body[2].id.name — reach a deeply nested property.
  • $..type — descendant traversal.

Use these exact expressions wherever the product supports RFC 9535 JSONPath. Record unsupported syntax rather than silently changing the test.
