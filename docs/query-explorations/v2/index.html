Common starter queries

$.rawAst.program.body[*].type

Read the type of every top-level AST statement.

$.rawAst.program.body[2]

Select the third statement.

$..type

Find every type property recursively.

$.rawAst.program.body[?@.type == "ImportDeclaration"]

Filter statements by node type.

V2 is a local learning implementation inspired by the capabilities being studied. It does not embed or redistribute the external products. Query evaluation here is a focused experimental subset, not a claim of full RFC 9535 conformance.
