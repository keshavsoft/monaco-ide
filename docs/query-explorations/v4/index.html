Architecture

index.json

Lab identity, description, default query and enabled capabilities.

bindings.json

Declarative event, selector and action mappings. One delegated listener per event type.

actions.js

Named behavior functions, separate from event wiring.

index.js

Loads the shared JSON, imports the blueprint and behavior, then wires the playground.

V4 is the story + playground layer. V1, V2 and V3 remain available as earlier iterations. The query evaluator remains an explicitly limited experimental subset of RFC 9535.
