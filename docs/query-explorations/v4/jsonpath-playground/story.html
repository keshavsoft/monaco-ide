RFC 9535 query and transformation workbench

How this experiment works

This describes our KeshavSoft learning implementation: how the shared JSON is represented, selected and changed in this playground.

01

Query authoring

The query editor is a language-aware surface, not simply a text field. It can offer completion, diagnostics, formatting and function help.

02

Node-list results

A JSONPath query selects nodes. Each result should retain both its value and its location in the source document.

03

Normalized paths

Normalized paths provide a stable structural address for selected nodes. They are useful for navigation and later edits.

04

Transformations

Replacement and deletion operate on selected nodes. Mutations should be explicit and should update the source document in a predictable way.

What we learned

RFC 9535 query evaluation returns selected nodes, not just values. Retaining node identity and normalized paths is essential when the user wants to navigate or modify the original JSON.

Does it use Monaco?

The public guide describes a dedicated JSONPath editor with syntax highlighting, diagnostics, completion, signature help and hover documentation. The public material we reviewed does not establish that it uses Monaco specifically, so we should not label it Monaco-based without inspecting its implementation.
